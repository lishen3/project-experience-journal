# Project Experience Journal Skill

`project-experience-journal` 是一个面向 Codex、Claude Code 等编程 Agent 的通用项目经历总结 Skill。它根据当前对话、用户笔记、项目文件和可选 Git 证据，生成按日期组织、适合复盘或放入 Word 的项目经历记录。

当前版本：`v0.1.0`

## 1. 项目解决什么问题

项目推进过程通常散落在聊天、代码修改、实验结果和临时笔记中，事后很难准确回答：

- 每天实际完成了什么；
- 使用了哪些知识、技巧、方法和策略；
- 哪些关键决策推动了项目；
- 结果经过了什么验证；
- 项目体现了用户什么能力；
- 哪些工作由用户完成，哪些属于 AI 辅助。

本 Skill 将这些证据整理为日期明确、项目相关、可追溯的经历记录。它不会读取不可见的历史对话，也不会把 AI 完成的工作冒充为用户能力。

## 2. 主要功能

- 根据当前对话和用户材料生成每日项目经历。
- 可选读取项目文件、测试结果和 Git 历史作为补充证据。
- 按日期记录目标、行动、方法、决策、成果、问题和下一步。
- 区分用户贡献、AI 辅助、团队贡献和贡献者未知的工作。
- 根据项目类型调整重点：
  - 数学建模：数据、假设、模型、求解、检验和论文推进；
  - 软件开发：需求、实现、测试、缺陷、性能和版本变化；
  - 研究与课程：研究问题、资料、实验、论证和学习成果。
- 支持单日记录、周报、月报、完整项目总结和简历项目描述。
- 提供脚本，将结构化项目经历导出为 `.docx`。
- 提供公开前安全检查脚本，扫描密钥、个人信息线索、本地绝对路径和临时文件。

## 3. 安装方法

### Codex

将整个目录复制到 Codex 的 Skills 目录：

```text
~/.codex/skills/project-experience-journal/
```

不要只复制 `SKILL.md`，Word 导出和安全检查还需要 `scripts/` 与 `references/`。

### Claude Code

将整个目录复制到：

```text
~/.claude/skills/project-experience-journal/
```

### Word 导出依赖

```bash
python -m pip install -r requirements.txt
```

当前唯一 Python 依赖是 `python-docx`。

## 4. 使用方法

在支持 Agent Skills 的会话中提出类似请求：

```text
使用 project-experience-journal，总结我今天在这个项目中的推进，输出为Word。
```

也可以指定用途和范围：

```text
根据当前对话和最近一周的Git记录，生成项目周报。区分我完成的工作和AI辅助工作，并提炼可以用于面试的能力证据。
```

```text
总结本次数学建模项目经历，按日期记录数据处理、模型选择、关键假设、求解验证、论文推进和下一步计划。
```

Skill 默认只使用当前可见对话与明确授权读取的文件。需要总结旧对话时，请提供导出的对话文本或既有笔记。

## 5. 输入输出示例

### 示例输入

```text
项目：校园活动报名系统
日期：2026-08-18
今天我确定使用二维码签到，修改了重复签到校验，并让AI帮我补充了单元测试。
测试显示重复请求不会生成第二条签到记录。下一步准备增加管理员导出功能。
```

### 示例输出

```markdown
# 项目实践与能力成长记录

## 2026-08-18｜校园活动报名系统

### 当日目标
完善签到流程，避免重复签到产生错误数据。

### 我完成的工作
- 确定二维码作为现场签到入口。
- 明确重复签到应保持幂等，不重复生成记录。
- 检查并确认重复请求的测试结果。

### AI辅助与团队协作
- 使用AI辅助补充重复签到相关单元测试，最终结果由我检查确认。

### 使用的方法与策略
- 采用幂等性设计处理重复请求。
- 通过单元测试验证同一签到请求不会创建第二条记录。

### 项目推进与可验证结果
- 重复签到校验已完成；测试结果表明重复请求只保留一条签到记录。

### 体现的能力
- 能把现场业务风险转换为明确的软件约束。
- 能使用自动化测试验证关键业务规则。

### 下一步计划
- 增加管理员签到数据导出功能。
```

### Word 输出

准备符合 `references/input-schema.md` 的 JSON 后运行：

```bash
python scripts/render_journal_docx.py examples/example-input.json project-experience.docx
```

脚本生成带主标题、日期标题、分节标题和项目符号的 Word 文档。

## 隐私与公开边界

- 发布 Skill 不等于发布任何使用该 Skill 的项目材料。
- 仓库示例必须是虚构或彻底匿名化的数据。
- 不提交真实对话、题目附件、项目日报、生成的 Word 文件或本地配置。
- 发布前运行：

```powershell
pwsh -NoProfile -File scripts/check_public_safety.ps1 -Root .
```
